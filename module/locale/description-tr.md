# Map Editor Improvements

Harita düzenleyicide arazi şekillendirmek ve kale inşa etmek için daha fazla araç. Yeni çeşitler yerleştirin, desteklenen binaları döndürün, damlalıkla arazi kopyalayın ve düzenlemeleri geri alın. İstediğiniz araçları Kullanım kolaylığı → Harita düzenleyici altında seçin.
